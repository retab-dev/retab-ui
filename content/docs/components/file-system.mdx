File System turns an object-store manifest into a navigable document workspace.
It accepts flat file and folder records, infers folder chains, and presents the
same source set through list, grid, columns, and gallery views.

Use it when users need to browse generated documents, uploaded files, extraction
artifacts, or case workspaces without leaving the document viewer surface.

## Installation

```bash
pnpm dlx shadcn@latest add @retab/file-system
```

For the demo block:

```bash
pnpm dlx shadcn@latest add @retab/file-system-block
```

## Example

<FileSystemDemo />

Open the full-page demo at [/view/blocks/file-system](/view/blocks/file-system).

```tsx
import { FileSystem, type FileSystemItem } from "@/components/ui/file-system"

const items: FileSystemItem[] = [
  {
    kind: "file",
    path: "research/attention.pdf",
    mimeType: "application/pdf",
    source: {
      kind: "url",
      url: "/samples/attention.pdf",
      fileName: "attention.pdf",
      mimeType: "application/pdf",
    },
  },
]

export function Documents() {
  return <FileSystem items={items} title="Workspace" />
}
```

## Viewer Composition

`FileSystem` is the easy API. The same viewer can be composed from named parts
when the surrounding workflow owns the frame:

```tsx
<FileSystemViewerProvider items={items} title="Workspace">
  <ViewerRoot>
    <FileSystemViewerHeader />
    <ViewerBody>
      <ViewerSidebar>
        <FileSystemViewerTree />
      </ViewerSidebar>
      <ViewerSurface>
        <FileSystemViewerSelectedFile />
      </ViewerSurface>
    </ViewerBody>
  </ViewerRoot>
</FileSystemViewerProvider>
```

The provider owns path, query, view, selection, lazy loading, and source
resolution. The viewer primitives own layout. `FileSystemViewerSelectedFile`
resolves the selected file to a `ViewerSource` and renders it with `FileViewer`.

## Useful Behaviors

- Accepts a flat manifest and infers missing parent folders.
- Shares selection, preview, search, filters, and sort state across list, grid,
  columns, and gallery views.
- Renders the list view with Pierre Trees for virtualized tree navigation,
  keyboard behavior, and icon handling.
- Uses `FileThumbnail` for compact previews and `FileViewer` for the selected
  file preview.
- Supports controlled `view`, `selectedPath`, and `query` state.
- Supports lazy folders through `loadChildren`.
- Resolves file sources on demand through `resolveSource`.

## API Reference

### FileSystem

| Prop                  | Type                                              | Default | Required |
| --------------------- | ------------------------------------------------- | ------- | -------- |
| `items`               | `FileSystemItem[]`                                | `-`     | Yes      |
| `title`               | `string`                                          | `Files` | No       |
| `className`           | `string`                                          | `-`     | No       |
| `defaultPath`         | `string`                                          | `""`    | No       |
| `defaultView`         | `"list" \| "grid" \| "columns" \| "gallery"`      | `list`  | No       |
| `view`                | `"list" \| "grid" \| "columns" \| "gallery"`      | `-`     | No       |
| `onViewChange`        | `(view) => void`                                  | `-`     | No       |
| `defaultQuery`        | `Partial<FileSystemQueryState>`                   | `-`     | No       |
| `query`               | `Partial<FileSystemQueryState>`                   | `-`     | No       |
| `onQueryChange`       | `(query) => void`                                 | `-`     | No       |
| `selectedPath`        | `string \| null`                                  | `-`     | No       |
| `defaultSelectedPath` | `string \| null`                                  | `null`  | No       |
| `onSelectionChange`   | `(item) => void`                                  | `-`     | No       |
| `loadChildren`        | `(args) => Promise<FileSystemLoadChildrenResult>` | `-`     | No       |
| `resolveSource`       | `(args) => Promise<ViewerSource \| null>`         | `-`     | No       |
| `onFileOpen`          | `(file, source) => void`                          | `-`     | No       |
| `renderFileActions`   | `(file) => React.ReactNode`                       | `-`     | No       |
| `renderMetadata`      | `(item) => React.ReactNode`                       | `-`     | No       |
