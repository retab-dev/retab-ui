Renders a Retab split result: named subdocuments, each owning a set of pages.

<SplitViewerDemo />

## Viewer Composition

Compose split results from the split provider and named split parts. The
document child is the only required extension point: it renders the source
document and connects document page events back to split navigation with
`useSplitViewerDocumentControls`.
`SplitViewerRoot` is the split-flavored wrapper around the shared `<ViewerRoot>`
primitive. The underlying layout primitive remains `<ViewerRoot`, while the
split provider owns segment state.

```tsx
function SplitDocument() {
  const controls = useSplitViewerDocumentControls()

  return (
    <PdfViewer
      ref={controls.setDocumentHandle}
      source={source}
      bare
      onVisiblePageChange={controls.onCurrentPageChange}
      onScrollProgressChange={controls.onScrollProgressChange}
    />
  )
}

export function Example() {
  return (
    <SplitViewerProvider result={result}>
      <SplitViewerRoot>
        <SplitViewerHeader />
        <SplitViewerBody>
          <SplitViewerSidebar>
            <SplitViewerPageRail />
          </SplitViewerSidebar>
          <SplitViewerSurface>
            <SplitViewerLegend />
            <SplitViewerDocument>
              <SplitDocument />
            </SplitViewerDocument>
          </SplitViewerSurface>
        </SplitViewerBody>
      </SplitViewerRoot>
    </SplitViewerProvider>
  )
}
```

`SplitViewerHeader` owns the full-width viewer title row.
`SplitViewerSidebar` is body-scoped, so the page rail starts below the
header. `SplitViewerLegend` lives inside `SplitViewerSurface` above the
document, which lets the rail dominate the legend and document body without
taking over the header.
`SplitViewerDocument` only frames the selected document child; it does not
receive hidden layout slots.

## Usage

`SplitViewer` is the easy API for a split result. It preassembles the same
provider and named parts; the source document remains an explicit child, and
document coordination comes from `useSplitViewerDocumentControls`.

```tsx
export function EasyExample() {
  return (
    <SplitViewer result={result}>
      <SplitDocument />
    </SplitViewer>
  )
}
```
