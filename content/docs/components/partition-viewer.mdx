Renders a Retab partition result: keyed chunks, each owning a set of pages.

## Viewer Composition

Compose the partition surface from `PartitionViewerProvider`, the shared viewer
layout primitives, and the named partition parts. Source documents register
their document handle and page callbacks with
`usePartitionViewerDocumentControls`.

```tsx
function SourceDocument() {
  const controls = usePartitionViewerDocumentControls()

  return (
    <PdfViewerPages
      ref={controls.setDocumentHandle}
      bare
      className="h-full"
      onVisiblePageChange={controls.onCurrentPageChange}
      onScrollProgressChange={controls.onScrollProgressChange}
    />
  )
}

export function CompositionExample() {
  return (
    <PartitionViewerProvider result={result}>
      <FileViewer source={source}>
        <PdfViewerProvider>
          <FileViewerHeader>
            <FileViewerTitle />
            <PartitionViewerHeaderMeta />
            <FileViewerControls />
          </FileViewerHeader>
          <FileViewerBody>
            <FileViewerSurface>
              <PartitionViewerLegend />
              <PartitionViewerRibbon />
              <PartitionViewerDocument document={<SourceDocument />} />
            </FileViewerSurface>
          </FileViewerBody>
        </PdfViewerProvider>
      </FileViewer>
    </PartitionViewerProvider>
  )
}
```

## Usage

`PartitionViewer` is the easy API. It preassembles the same provider and named
parts; pass the source document explicitly through `document`.

```tsx
export function Example() {
  return (
    <PartitionViewer
      source={source}
      result={result}
      document={<SourceDocument />}
    />
  )
}
```
