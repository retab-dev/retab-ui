title: Segment Sidebar

`SegmentSidebar` is the "list" surface over a page-segmented result (partition
chunks or split subdocuments). Each row shows a color swatch, label, page
ranges, page count, and — when present — a confidence bar.

Hovering, keyboard focus, and persistent selection are separate states.
Clicking fires `onSelect` so the host can scroll the document to the segment's
first page. Wire it to the same `useSegmentInteraction` object as a
[legend](/docs/components/legend) for a coordinated layout.

## In a split viewer

Mounted as the left rail of a [split viewer](/docs/components/split-viewer), the
sidebar shares hover, focus, and selection with the legend and page timeline —
hover or focus a row to dim the others everywhere, click to select and scroll
the document to that subdocument's first page.

```bash
npx shadcn@latest add @retab/segment-sidebar
```

## Usage

Reduce a partition or split result to `Segment[]` with `toSegments`, then render
the sidebar against your own interaction state:

```tsx
import { toSegments } from "@/lib/segments"
import { SegmentSidebar } from "@/components/ui/segment-sidebar"
import { useSegmentInteraction } from "@/components/ui/use-segment-interaction"

// partition: [{ key, pages }]   split: [{ name, pages }]
const segments = toSegments(result.output)

export function Example() {
  const interaction = useSegmentInteraction()
  return (
    <SegmentSidebar
      segments={segments}
      interaction={interaction}
      onSelect={(segment) => scrollToPage(segment.pages[0])}
      unitLabel="subdocument"
    />
  )
}
```

For caller-owned selection state, build the same `interaction` object with
`useControlledSegmentInteraction`; do not pass selection props to the sidebar.

## Props

| Prop          | Type                         | Description                                                             |
| ------------- | ---------------------------- | ----------------------------------------------------------------------- |
| `segments`    | `Segment[]`                  | Labels + pages + colors (use `toSegments`).                             |
| `interaction` | `SegmentInteraction`         | Shared hover/focus/selection state.                                     |
| `onSelect`    | `(segment: Segment) => void` | Fired when a segment is clicked, after shared selection is requested.   |
| `currentPage` | `number \| null`             | 1-based current page; owning segments receive current-page state.       |
| `unitLabel`   | `string`                     | Row noun, e.g. `"chunk"` or `"subdocument"`. Defaults to `"segment"`.   |
| `showUnused`  | `boolean`                    | Show segments with zero pages too. Defaults to `true`.                  |
| `className`   | `string`                     | Container class.                                                        |
