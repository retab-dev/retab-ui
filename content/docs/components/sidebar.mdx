---
title: Segment Sidebar
description: A selectable list of document segments with page ranges and confidence, driven by shared hover/selection state.
---

`SegmentSidebar` is the "list" surface over a page-segmented result (partition
chunks or split subdocuments). Each row shows a color swatch, label, page
ranges, page count, and — when present — a confidence bar.

Hovering a row raises `activeId` (dimming the others); clicking fires `onSelect`
so the host can scroll the document to the segment's first page. Wire it to the
same shared state as a [legend](/docs/components/legend) for a coordinated layout.

## Installation

```bash
npx shadcn@latest add @retab/segment-sidebar
```

## Usage

Reduce a partition or split result to `Segment[]` with `toSegments`, then render
the sidebar against your own `activeId` state:

```tsx
import { useState } from "react"
import { toSegments } from "@/lib/segments"
import { SegmentSidebar } from "@/components/ui/segment-sidebar"

// partition: [{ key, pages }]   split: [{ name, pages }]
const segments = toSegments(result.output)

export function Example() {
  const [activeId, setActiveId] = useState<string | null>(null)
  return (
    <SegmentSidebar
      segments={segments}
      activeId={activeId}
      onActivate={setActiveId}
      onSelect={(segment) => scrollToPage(segment.pages[0])}
      unitLabel="subdocument"
    />
  )
}
```

## Props

| Prop | Type | Description |
| --- | --- | --- |
| `segments` | `Segment[]` | Labels + pages + colors (use `toSegments`). |
| `activeId` | `string \| null` | Highlighted segment (shared hover/selection); dims the others. |
| `onActivate` | `(id: string \| null) => void` | Fired on hover in/out. |
| `onSelect` | `(segment: Segment) => void` | Fired on click — e.g. to jump the document to the segment's first page. |
| `unitLabel` | `string` | Row noun, e.g. `"chunk"` or `"subdocument"`. Defaults to `"segment"`. |
| `showUnused` | `boolean` | Show segments with zero pages too. Defaults to `true`. |
| `className` | `string` | Container class. |
