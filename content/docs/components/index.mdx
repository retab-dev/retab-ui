title: Components
description: Headless React components for Retab document AI products, installed as source through the shadcn registry.
---

Retab UI components are headless and unstyled — install each as source with the
shadcn CLI and theme it to match your product.

## Forms & schemas

- [Data Cell](/docs/components/data-cell) — a lightweight editable cell for scalar document data: text, numbers, booleans, dates, times, and date-times.
- [JSON Form](/docs/components/json-form) — a JSON-Schema-driven form built entirely on shadcn's FormField abstraction.
- [Dropzone](/docs/components/dropzone) — build custom file intake surfaces with the headless drag/drop and file input primitive.
- [File Uploader](/docs/components/file-uploader) — a polished document upload area built from Dropzone and File Thumbnail.
- [JSON Table](/docs/components/json-table) — render structured extraction data as a schema-driven, virtualized table.
- [Schema Builder](/docs/components/schema-builder) — build the JSON Schema that drives a Retab extraction, the same editor used in the Retab dashboard.
- [Property Form](/docs/components/property-form) — the edit form for a single schema property — the content of the Schema Builder's Edit Property dialog.

## File viewers

The file-format viewers — PDF, image, CSV, XLSX, DOCX, PPTX, and the universal
File Viewer — live in their own [Viewers](/docs/viewers) section.

- [File Thumbnail](/docs/components/file-thumbnail) — render compact file preview images with a skeleton, fade transition, and fallback state.
- [File System](/docs/components/file-system) — browse a flat object-store manifest with list, grid, columns, thumbnails, lazy folders, and a persistent FileViewer preview.

## Result viewers

- [Extract Viewer](/docs/components/extract-viewer) — link extracted fields to their sources: hover a field to highlight where its value came from in the document.
- [Layout Blocks](/docs/components/layout-blocks) — inspect OCR blocks, lines, and words over the source document image, starting from Google Document AI output.
- [Edit Viewer](/docs/components/edit-viewer) — render a Retab edit result: source, preview, filled output, and the detected form fields.
- [Classification Viewer](/docs/components/classification-viewer) — render a Retab classification result: the predicted category and reasoning over the document.
- [Partition Viewer](/docs/components/partition-viewer) — render a Retab partition result: keyed chunks over the source document.
- [Split Viewer](/docs/components/split-viewer) — render a Retab split result: named subdocuments over the source document.
- [Segment Sidebar](/docs/components/segment-sidebar) — a selectable list of document segments with page ranges and confidence, for page-segmented results (partition, split).
- [Segment Legend](/docs/components/legend) — a compact color key for page-segmented results, with bar, floating, and rail variants.
