Retab UI components are headless and unstyled — install each as source with the
shadcn CLI and theme it to match your product.

## File Viewer

[File Viewer](/docs/components/file-viewer) is the flagship document component.
It owns file identity, header composition, body layout, sidebar state, renderer
routing, and file-scoped controls. Format renderers and navigation modules live
inside this category:

- [Anatomy](/docs/components/file-viewer/anatomy) — the compound component shape.
- [Header](/docs/components/file-viewer/header) — title, metadata, controls, and sidebar trigger.
- [Navigation](/docs/components/file-viewer/navigation) — the optional rail slot and file-scoped navigation controls.
- [FileViewerAttachments](/docs/components/file-viewer/navigation/file-viewer-attachments) — attachment rows inside the sidebar slot.
- [FileViewerSegments](/docs/components/file-viewer/navigation/file-viewer-segments) — segment rows inside the sidebar slot.
- [FileViewerSegmentLegend](/docs/components/file-viewer/navigation/file-viewer-segment-legend) — compact segment color key.
- [Email](/docs/components/file-viewer/renderers/email) — compound MIME viewing with File Viewer leaves.
- [PDF](/docs/components/file-viewer/renderers/pdf), [Image](/docs/components/file-viewer/renderers/image), [CSV](/docs/components/file-viewer/renderers/csv), [Text](/docs/components/file-viewer/renderers/text), and Office renderers.

## Forms & data

- [Data Cell](/docs/components/data-cell) — a lightweight editable cell for scalar document data: text, numbers, booleans, dates, times, and date-times.
- [JSON Form](/docs/components/json-form) — a JSON-Schema-driven form built entirely on shadcn's FormField abstraction.
- [JSON Table](/docs/components/json-table) — render structured extraction data as a schema-driven, virtualized table.
- [Schema Builder](/docs/components/schema-builder) — build the JSON Schema that drives a Retab extraction, the same editor used in the Retab dashboard; includes the Property Form subcomponent (the Edit Property dialog body).
- [Parse Viewer](/docs/components/parse-viewer) — render Retab parse output as page-preserving markdown with source-document sync.

## File intake

- [Dropzone](/docs/components/dropzone) — build custom file intake surfaces with the headless drag/drop and file input primitive.
- [File Thumbnail](/docs/components/file-thumbnail) — render compact file preview images with a skeleton, fade transition, and fallback state.
