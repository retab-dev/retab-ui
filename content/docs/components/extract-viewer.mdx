A **source** is the provenance of an extracted value: where in the document it
was found. Extract and extraction viewers use the anchored-document model to
turn those source locations into interactive anchors.

Hover or select a field; its anchor highlights in the PDF and scrolls into view.

## Viewer Composition

Extraction is not a special PDF viewer. It is a domain composition:

```tsx
<AnchoredDocumentProvider items={items} target={target}>
  <ViewerRoot>
    <ViewerBody>
      <ViewerSurface>
        <PdfViewer renderPageOverlay={renderPageOverlay} />
      </ViewerSurface>
      <ViewerSidebar>
        <JsonForm anchorLink={link} />
      </ViewerSidebar>
    </ViewerBody>
  </ViewerRoot>
</AnchoredDocumentProvider>
```

The pieces stay separate:

| Piece                      | Role                                                                 |
| -------------------------- | -------------------------------------------------------------------- |
| `document-source`          | Retab source response types and flattening helpers.                  |
| `AnchoredDocumentProvider` | preview, selected, active item state, and target navigation.         |
| `JsonForm`                 | field renderer that reports field paths through `anchorLink`.        |
| `pdf-anchor-target`        | PDF adapter: source-to-anchor projection, scroll target, and overlay. |
| `PdfViewer`                | leaf viewer that renders the PDF source.                             |

the target adapter navigates the leaf viewer.

## Source Data

Sources come from Retab's `GET /v1/extractions/{id}/sources`
(`ExtractionSourcesResponse`): the extracted value tree plus a parallel
`sources` tree whose leaves are `{ value, source }`. A `Source` is
`{ content, anchor }`, where the `anchor` is a discriminated union per document
format. For PDFs, the source anchor is a normalized page bounding box.

`extractionSourcesToSourceMap` flattens that tree into a path-keyed lookup. The
keys are dotted paths (`owner.name`, `properties.0.gas_volume`) — the same paths
used by `JsonForm`, so each field path can also be an anchored item id.

```ts
import { extractionSourcesToSourceMap } from "@/lib/document-source"
import type { AnchoredItem } from "@/components/ui/anchored-document-viewer"
import { sourceToPdfAnchor } from "@/components/ui/pdf-anchor-target"

const sources = extractionSourcesToSourceMap(response.sources)
const items: AnchoredItem[] = Object.entries(sources).map(([id, source]) => ({
  id,
  anchor: sourceToPdfAnchor(source),
}))
```

## Composing JSON Form With The PDF Viewer

`JsonForm` accepts a `FieldAnchorLink`. Inside an
`AnchoredDocumentProvider`, get that link from `useAnchoredFieldLink` and pass
it to `anchorLink`. The PDF adapter reads the same provider to render the active
highlight.

<JsonFormSourcesDemo />

```tsx
import * as React from "react"

import { extractionSourcesToSourceMap } from "@/lib/document-source"
import {
  AnchoredDocumentProvider,
  type AnchoredItem,
  useAnchoredFieldLink,
} from "@/components/ui/anchored-document-viewer"
import {
  sourceToPdfAnchor,
  usePdfAnchoredOverlay,
  usePdfAnchoredTarget,
} from "@/components/ui/pdf-anchor-target"
import { PdfViewer, type PdfViewerHandle } from "@/components/ui/pdf-viewer"
import { JsonForm } from "@/components/json-form/json-form"

export function Example({ response, form }) {
  const viewerRef = React.useRef<PdfViewerHandle>(null)
  const target = usePdfAnchoredTarget(viewerRef)
  const sources = React.useMemo(
    () => extractionSourcesToSourceMap(response.sources),
    [response.sources]
  )
  const items = React.useMemo<AnchoredItem[]>(
    () =>
      Object.entries(sources).map(([id, source]) => ({
        id,
        anchor: sourceToPdfAnchor(source),
      })),
    [sources]
  )

  return (
    <AnchoredDocumentProvider items={items} target={target}>
      <ExampleContent
        form={form}
        schema={response.schema}
        viewerRef={viewerRef}
      />
    </AnchoredDocumentProvider>
  )
}

function ExampleContent({ form, schema, viewerRef }) {
  const link = useAnchoredFieldLink()
  const renderPageOverlay = usePdfAnchoredOverlay({ mode: "active" })

  return (
    <div className="flex h-full">
      <PdfViewer
        ref={viewerRef}
        source={{ kind: "url", url: "/document.pdf" }}
        bare
        className="min-w-0 flex-1"
        renderPageOverlay={renderPageOverlay}
      />
      <JsonForm form={form} schema={schema} anchorLink={link} />
    </div>
  )
}
```

To link a different field component, call `previewItem`, `selectItem`, or
`activateItem` from `useAnchoredDocument`. To support a different viewer, write
one target adapter that translates the shared document anchor into that viewer's
native scroll and overlay APIs.

## API

### `document-source`

| Export                         | Description                                                                                                                                |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `Source`                       | `{ content, anchor }` — a value's provenance.                                                                                              |
| `SourceAnchor`                 | Discriminated union on `kind`: `pdf_bbox`, `image_bbox`, `csv_cell`, `spreadsheet_cell`, `docx_text_span`, `docx_table_cell`, `text_span`. |
| `ExtractionSourcesResponse`    | The `/v1/extractions/{id}/sources` shape.                                                                                                  |
| `extractionSourcesToSourceMap` | Flatten the nested sources tree into a dotted-path lookup.                                                                                 |
| `SourceLocation` / `SourceArea` | A normalized page region (`page` + percent box).                                                                                          |
| `sourceLocationKey`            | Stable key for dedupe.                                                                                                                     |

### `anchored-document-viewer`

| Export                     | Description                                                                 |
| -------------------------- | --------------------------------------------------------------------------- |
| `AnchoredDocumentProvider` | Owns item-anchor preview, selection, activation, and target navigation.     |
| `AnchoredItem`             | `{ id, anchor, disabled? }`; use the field path as `id` for extraction UI.  |
| `FieldAnchorLink`          | Link shape accepted by `JsonForm`'s `anchorLink` prop.                     |
| `useAnchoredFieldLink`     | Returns a `FieldAnchorLink` from the active anchored-document provider.     |
| `useAnchoredDocument`      | Low-level access to active item, preview, select, activate, and clear APIs. |

### `pdf-anchor-target`

| Export                  | Description                                                                         |
| ----------------------- | ----------------------------------------------------------------------------------- |
| `sourceToPdfAnchor`     | Converts a Retab PDF source into the shared PDF document anchor.                    |
| `usePdfAnchoredTarget`  | Creates an `AnchoredDocumentTarget` over a `PdfViewer` ref.                         |
| `usePdfAnchoredOverlay` | Creates a `renderPageOverlay` callback for active or interactive anchored regions. |

The [Extract Viewer](/blocks#extract), [Extraction Viewer](/blocks#extraction-viewer),
and [JSON Form Sources](/blocks#json-form-sources) blocks are all compositions of
the same anchored-document system.
