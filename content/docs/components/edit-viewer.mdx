---
title: Edit Viewer
description: Renders a Retab edit result — original/filled document views and the detected form fields.
---

The edit viewer renders the output of a Retab **edit** beside its source
document: each detected form field is drawn as a bbox overlay on the page, and a
synced panel lists the fields with their inferred values. Hover or select a
field to highlight its region and scroll it into view; toggle **Original /
Filled** to stamp the filled values onto the form. The panel groups fields by
page and supports search and filled/empty filtering.

<EditViewerDemo />

The document is supplied through a `renderDocument` render-prop, which receives
an `EditDocumentContext` — a viewer `ref`, a `renderPageOverlay` callback, and an
`onVisiblePageChange` handler — to spread onto a `PdfViewer`. The fields come
from the edit result's `detectedFields` (each a `key`, `type`, `value`, and a
normalized `bbox`).
