The classification viewer renders the output of a Retab **classification**.
A classification is a single category over the whole document, so it renders as
plain result chrome over an optional source document. It does not manufacture a
fake document segment just to reuse split or partition visuals.

<ComponentPreview name="classification-viewer-demo" contentClassName="p-0" />

## Viewer Composition

Compose the classification surface from `ClassifierViewerProvider`, the shared
viewer layout primitives, and the named classifier parts. The provider owns the
category and reasoning state; the document remains an explicit node, typically
a [`PdfViewer`](/docs/components/file-viewer/renderers/pdf) rendered `bare`.

```tsx
<ClassifierViewerProvider result={result}>
  <ViewerRoot>
    <ClassifierViewerHeader />
    <ViewerBody>
      <ViewerSurface>
        <ClassifierViewerDocument document={<SourceDocument />} />
      </ViewerSurface>
    </ViewerBody>
  </ViewerRoot>
</ClassifierViewerProvider>
```

## Usage

`ClassifierViewer` is the easy API. It preassembles the same provider and named
parts; pass the source document explicitly through `document`.

```tsx
export function Example() {
  return <ClassifierViewer result={result} document={<SourceDocument />} />
}
```
