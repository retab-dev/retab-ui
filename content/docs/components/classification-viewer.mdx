---
title: Classification Viewer
description: Renders a Retab classification result — the predicted category and reasoning over the document.
---

The classification viewer renders the output of a Retab **classification**.
A classification is a single category over the whole document, so it reduces to
one segment — shown as a swatch + label in the **legend** over the source
**file**. It's the same file + legend system the split and partition viewers
use, with a single segment rather than bespoke chrome.

<ClassificationViewerDemo />

The source document is supplied through a `renderDocument` render-prop, which
receives `{ slots }` — a [`PdfViewerSlots`](/docs/viewers/pdf-viewer) you
spread onto your document surface, typically a
[`PdfViewer`](/docs/viewers/pdf-viewer). The category legend mounts in the
`top` slot, with the classification's reasoning as the legend's `caption`.
