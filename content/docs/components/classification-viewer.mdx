title: Classification Viewer

---

The classification viewer renders the output of a Retab **classification**.
A classification is a single category over the whole document, so it reduces to
one segment — shown as a swatch + label in the **legend** over the source
**file**. It's the same file + legend system the split and partition viewers
use, with a single segment rather than bespoke chrome.

<ClassificationViewerDemo />

## Viewer Composition

Compose the classification surface from `ClassifierViewerProvider`,
`ClassifierViewerHeader`, and a visible document surface. The provider owns the
category and reasoning state; the document remains an explicit child, typically
a [`PdfViewer`](/docs/viewers/pdf-viewer) rendered `bare`.

```tsx
<ClassifierViewerProvider result={result}>
  <ViewerRoot>
    <ClassifierViewerHeader />
    <ViewerBody>
      <ViewerSurface>
        <SourceDocument />
      </ViewerSurface>
    </ViewerBody>
  </ViewerRoot>
</ClassifierViewerProvider>
```

## Usage

Use `<ClassifierViewer result={result} />` when you only need the classification
header and default empty document surface. Use the provider parts when a source
document should be visible.
