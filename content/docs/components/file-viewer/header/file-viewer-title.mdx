`FileViewerTitle` renders the current file display name. It is the primary file
identity in the header.

## Usage

```tsx
<FileViewerHeader>
  <FileViewerTitle />
  <FileViewerMeta />
  <FileViewerControls />
</FileViewerHeader>
```

## Behavior

- Reads `descriptor.displayName` from file-viewer context — it takes no `source`
  or name prop of its own.
- Renders a `data-slot="file-viewer-title"` element with a truncating label and
  a native `title` tooltip, so long file names clip cleanly and stay readable on
  hover.
- Do not add a decorative file icon beside the title. The file name carries the
  identity; metadata and controls provide the surrounding context.

## API Reference

| Prop        | Type                          | Description                                          |
| ----------- | ----------------------------- | ---------------------------------------------------- |
| `className` | `string`                      | Class merged onto the title container.               |
| `...props`  | `React.ComponentProps<"div">` | Standard `div` props spread onto the title element.  |
