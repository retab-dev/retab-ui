`FileViewerMeta` renders passive facts about the current file: its MIME type or
category. It sits next to the title and never carries actions.

<ComponentPreview name="file-viewer-header-demo" />

## Usage

```tsx
<FileViewerHeader>
  <FileViewerTitle />
  <FileViewerMeta />
  <FileViewerControls />
</FileViewerHeader>
```

## Behavior

- Resolves its text from context as `resource.mimeType`, falling back to the
  descriptor's MIME type, then the detected category.
- Renders **nothing** when there is no metadata to show, so it never leaves an
  empty gap in the header.
- Renders a `data-slot="file-viewer-meta"` element with muted, truncating text.
- Metadata belongs next to the title on the left; actions belong in
  `FileViewerControls` on the right.

## API Reference

| Prop        | Type                           | Description                                          |
| ----------- | ------------------------------ | ---------------------------------------------------- |
| `className` | `string`                       | Class merged onto the metadata element.              |
| `...props`  | `React.ComponentProps<"span">` | Standard `span` props spread onto the element.       |
