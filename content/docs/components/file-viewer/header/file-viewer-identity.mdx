`FileViewerIdentity` renders the active file display name and passive metadata
from `FileViewerProvider` state.

```tsx
<FileViewerIdentity meta="responsive" />
```

## Behavior

- Reads `descriptor.displayName`, MIME type, and category from file viewer
  context. It does not take a `source`, `title`, or file name prop.
- Renders a `data-slot="file-viewer-identity"` wrapper with truncating text.
- The file name is the primary identity. Do not add decorative file-type icons
  beside it unless the surrounding workflow has a stronger reason.
- `meta="responsive"` hides passive metadata on small screens.

## API Reference

| Prop       | Type                                    | Description                                  |
| ---------- | --------------------------------------- | -------------------------------------------- |
| `meta`     | `"hidden" \| "responsive" \| "visible"` | Metadata visibility. Defaults to responsive. |
| `...props` | `React.ComponentProps<"div">`           | Standard div props; `className` is merged.   |
