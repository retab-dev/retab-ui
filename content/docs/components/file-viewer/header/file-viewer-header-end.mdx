`FileViewerHeaderEnd` is the trailing slot inside `FileViewerHeader`. Put
`FileViewerToolbar` and file-scoped actions here.

```tsx
<FileViewerHeaderEnd>
  <FileViewerToolbar extra={<ApproveButton />} />
</FileViewerHeaderEnd>
```

## Behavior

- Renders a `data-slot="file-viewer-header-end"` element.
- Uses `ms-auto` and shrink-safe sizing so controls remain aligned to the right.
- In `headerMode="outlets"`, projects its content to the `toolbar` header
  outlet when both header outlets are mounted.
- Keep it for file-scoped controls. Workflow panels, forms, and domain state
  should stay outside the File Viewer header.

## API Reference

| Prop       | Type                          | Description                                |
| ---------- | ----------------------------- | ------------------------------------------ |
| `children` | `React.ReactNode`             | Usually `FileViewerToolbar`.               |
| `...props` | `React.ComponentProps<"div">` | Standard div props; `className` is merged. |
