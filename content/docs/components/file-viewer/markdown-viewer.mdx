The Markdown Viewer renders Markdown as a document, not as code. It keeps
large documents virtualized internally, supports rendered and source-text modes,
and uses the same source-based API as the Text Viewer so inline text, URL, and
Blob sources all go through one resource path.

For new File Viewer Markdown routing, use the separate
[Pretext Markdown Viewer](/docs/components/file-viewer/pretext-markdown-viewer). That path is
the active replacement candidate and keeps page-like Markdown chunks as an
internal virtualization strategy only.

## Installation

```bash
npx shadcn@latest add @retab/markdown-document-viewer
```

## Usage

```tsx
import { MarkdownDocumentViewer } from "@/components/ui/markdown-document-viewer"

export function Example() {
  return (
    <MarkdownDocumentViewer
      source={{
        kind: "text",
        text: "# Notes\n\nMarkdown should wrap and render like a document.",
        fileName: "notes.md",
        mimeType: "text/markdown",
      }}
    />
  )
}
```

URL sources work the same way:

```tsx
<MarkdownDocumentViewer
  source={{
    kind: "url",
    url: "/samples/release-notes.md",
    fileName: "release-notes.md",
  }}
/>
```

## Features

- **Rendered/Text modes** — switch between rendered Markdown and wrapped source text.
- **Continuous virtualization** — only visible Markdown chunks mount, so long documents stay responsive without page breaks.
- **Source-faithful text mode** — frontmatter delimiters and blank-line spacing stay intact in Text mode.
- **GFM rendering** — headings, paragraphs, links, task lists, tables, blockquotes, footnotes, fenced code, images, and rules render as React-owned DOM.
- **Docs syntax** — GitHub alerts, directive callouts, typographic transforms, emoji shortcodes, and whitelisted component markdown render in the document surface.
- **Diagrams** — Mermaid fences render through a measured diagram surface with copy and fallback states.
- **Safe fallbacks** — raw HTML and unsafe URLs do not become live executable DOM.
- **Document controls** — mode, zoom, fit width, copy, and download are built in.

Unsupported syntax stays inert: arbitrary MDX JavaScript, imports, event
handlers, active iframes, remote component resolution, and executable HTML are
not run by the viewer.

## API Reference

| Prop        | Type                    | Description                                                                |
| ----------- | ----------------------- | -------------------------------------------------------------------------- |
| `source`    | `TextDocumentSource`    | Required source descriptor. Supports URL, Blob, and inline text resources. |
| `className` | `string`                | Optional class on the viewer container.                                    |
| `controls`  | `boolean`               | Show mode, zoom, copy, and download controls. Defaults to `true`.          |
| `highlight` | `TextLineRange \| null` | 1-based inclusive source-line range to highlight.                          |
| `bare`      | `boolean`               | Drop the outer border/background so the viewer fills its container.        |
| `maxBytes`  | `number`                | Maximum text payload size accepted by the viewer.                          |
| `maxLines`  | `number`                | Maximum number of source lines accepted by the viewer.                     |
