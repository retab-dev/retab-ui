---
title: Source Evidence Review
description: Link extracted values to page-local source evidence over a file document.
component: true
---

Source evidence review is a workflow composition. The evidence model owns
field-to-source semantics; File Viewer owns the file surface and renderer
controls.

```tsx
<FileViewer source={source} defaultOpen>
  <FileViewerHeader>
    <FileViewerSidebarTrigger />
    <FileViewerTitle />
    <FileViewerMeta />
    <FileViewerControls />
  </FileViewerHeader>
  <FileViewerBody>
    <FileViewerSidebar aria-label="Sources">
      <SourceFields fields={fields} />
    </FileViewerSidebar>
    <FileViewerSurface>
      <FileViewerDocument />
    </FileViewerSurface>
  </FileViewerBody>
</FileViewer>
```

Keep evidence conversion in the workflow adapter. File Viewer should not learn
schemas, field names, or extraction run semantics.
