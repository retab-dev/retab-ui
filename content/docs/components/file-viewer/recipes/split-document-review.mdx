---
title: Split Document Review
description: Review semantic document segments beside a file-backed source document.
component: true
---

Split review is a domain workflow over a file-backed document. The workflow
owns split semantics; File Viewer owns the source file surface.

```tsx
<SplitViewer
  source={source}
  result={splitResult}
  document={<FileViewer source={source} bare className="h-full" />}
/>
```

When the workflow needs richer page control, keep the document handle inside the
split viewer and use file renderer primitives such as `PdfViewerPages`.

See [Split Viewer](/docs/components/split-viewer) for the full result viewer.
