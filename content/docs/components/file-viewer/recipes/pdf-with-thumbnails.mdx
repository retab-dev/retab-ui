---
title: PDF With Thumbnails
description: Compose File Viewer, PDF state, a thumbnail sidebar, and PDF pages.
component: true
---

```tsx
<FileViewer source={{ kind: "url", url, fileName: "document.pdf" }} defaultOpen>
  <PdfViewerProvider>
    <FileViewerHeader>
      <FileViewerSidebarTrigger />
      <FileViewerTitle />
      <FileViewerMeta />
      <FileViewerControls />
    </FileViewerHeader>
    <FileViewerBody>
      <FileViewerSidebar aria-label="PDF pages">
        <PdfViewerThumbnails />
      </FileViewerSidebar>
      <FileViewerSurface>
        <PdfViewerPages />
      </FileViewerSurface>
    </FileViewerBody>
  </PdfViewerProvider>
</FileViewer>
```

Use this when the page rail is part of the file viewer itself. Use
`PdfThumbnailRail` only when a parent workflow already owns page state.
