---
title: Email With Attachments
description: Compose an email message with a parts sidebar and File Viewer leaves.
component: true
---

```tsx
<EmailViewerProvider message={message}>
  <ViewerRoot defaultOpen sidebarSide="right">
    <EmailViewerHeader />
    <ViewerBody className="flex-col md:flex-row">
      <ViewerSurface>
        <EmailViewerContent />
      </ViewerSurface>
      <ViewerSidebar aria-label="Email parts">
        <EmailViewerPartsSidebar />
      </ViewerSidebar>
    </ViewerBody>
  </ViewerRoot>
</EmailViewerProvider>
```

Email owns MIME semantics. File Viewer owns attachment leaves. A selected
attachment should render as `FileViewer bare` inside the email surface.
