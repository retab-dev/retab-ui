---
title: FileViewerSidebarTrigger
description: A button that toggles the nearest File Viewer sidebar.
component: true
---

`FileViewerSidebarTrigger` toggles the nearest `FileViewerSidebar`. Put it in
`FileViewerHeader`, a toolbar, or another file-scoped control surface.

```tsx
<FileViewer source={source} defaultOpen>
  <FileViewerHeader>
    <FileViewerSidebarTrigger />
    <FileViewerTitle />
    <FileViewerMeta />
    <FileViewerControls />
  </FileViewerHeader>
  <FileViewerBody>
    <FileViewerSidebar aria-label="PDF pages" />
    <FileViewerSurface>
      <FileViewerDocument />
    </FileViewerSurface>
  </FileViewerBody>
</FileViewer>
```

The trigger targets the nearest `FileViewer` scope. Nested file viewers get
their own sidebar state.
