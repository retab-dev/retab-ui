Dropzone is the headless file-intake primitive. It owns drag/drop mechanics,
file input wiring, accept validation, max-size and max-file rejection,
controlled/uncontrolled file state, and accessibility prop getters.

It does not render icons, thumbnails, copy, grids, cards, progress rows, or
upload transport. Use [File Uploader](/docs/components/file-uploader) for the
default Retab visual upload area.

## Installation

```bash
npx shadcn@latest add @retab/dropzone
```

## Example

<DropzoneDemo />

```tsx
import { useDropzone } from "@/components/ui/dropzone"

export function UploadTarget() {
  const dropzone = useDropzone({
    accept: "application/pdf,image/*,.docx,.xlsx,.csv",
    maxFiles: 3,
    onFilesAccepted(files) {
      console.log(files)
    },
  })

  return (
    <div {...dropzone.getRootProps(dropzone.getTriggerProps())}>
      <input {...dropzone.getInputProps()} />
      Drop or browse files
    </div>
  )
}
```

## Behavior

- Uses the same commit path for drag/drop and native file input selection.
- Opens the native file picker through `openFileDialog` or trigger props.
- Tracks nested drag enter/leave events so active state does not flicker.
- Highlights only when the drag payload contains files.
- Accepts MIME types, wildcard MIME types such as `image/*`, and extensions.
- Supports controlled and uncontrolled file state.
- Supports `multiple`, `maxFiles`, and `maxSize`.
- Exposes `removeFile` and `clearFiles`.
- Composes consumer event handlers and respects `event.defaultPrevented`.

## API Reference

### `useDropzone`

| Prop              | Type                                            | Default | Required |
| ----------------- | ----------------------------------------------- | ------- | -------- |
| `accept`          | `string`                                        | `-`     | No       |
| `defaultFiles`    | `DropzoneFileItem[]`                            | `[]`    | No       |
| `disabled`        | `boolean`                                       | `false` | No       |
| `files`           | `DropzoneFileItem[]`                            | `-`     | No       |
| `maxFiles`        | `number`                                        | `-`     | No       |
| `maxSize`         | `number`                                        | `-`     | No       |
| `multiple`        | `boolean`                                       | `true`  | No       |
| `onFilesAccepted` | `(files: File[]) => void`                       | `-`     | No       |
| `onFilesChange`   | `(files: DropzoneFileItem[]) => void`           | `-`     | No       |
| `onFilesRejected` | `(rejections: DropzoneFileRejection[]) => void` | `-`     | No       |

### Return Value

| Field             | Type                                                      |
| ----------------- | --------------------------------------------------------- |
| `files`           | `DropzoneFileItem[]`                                      |
| `acceptedFiles`   | `File[]`                                                  |
| `rejectedFiles`   | `DropzoneFileRejection[]`                                 |
| `isDragging`      | `boolean`                                                 |
| `isFocused`       | `boolean`                                                 |
| `isDisabled`      | `boolean`                                                 |
| `hasFiles`        | `boolean`                                                 |
| `clearFiles`      | `() => void`                                              |
| `openFileDialog`  | `() => void`                                              |
| `removeFile`      | `(fileId: string) => void`                                |
| `getRootProps`    | `(props?) => React.HTMLAttributes<HTMLElement>`           |
| `getInputProps`   | `(props?) => React.InputHTMLAttributes<HTMLInputElement>` |
| `getTriggerProps` | `(props?) => React.HTMLAttributes<HTMLElement>`           |

The package also exports `DropzoneRoot`, `DropzoneInput`, `DropzoneTrigger`,
`useDropzoneContext`, `matchesDropzoneAccept`, `validateDropzoneFile`,
`validateDropzoneFiles`, and `formatDropzoneBytes`.
