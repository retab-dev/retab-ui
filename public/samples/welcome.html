Welcome to Retab UI

Overview

Every viewer is built around the same ideas: load with Suspense, render only what is near the viewport, and keep the heavy parser off the main thread.

Composition happens through slots. A document surface exposes top, bottom, left, right, and overlay regions, so legends, ribbons, and citation layers attach without forking the viewer.

Source linking ties extracted values back to the exact pixels or lines they came from, so a reviewer can audit every field in one glance.

Retab turns messy documents into structured data. The registry ships the same viewers and primitives the Retab dashboard uses, as copy-paste components.
