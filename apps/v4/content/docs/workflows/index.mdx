---
title: Workflows
description: Building blocks for visualizing and inspecting the steps of a document workflow — the requests it makes, the data it returns, and how each stage connects.
---

Workflow components render the moving parts of a pipeline: the external calls a
run makes, the payloads that flow between steps, and the state of each stage.
They're presentation primitives — you feed them the data from a run and they show
it clearly.

## Components

- [Run Timeline](/docs/workflows/run-timeline) — a run as a list of its steps
  beside the selected step's inspector; the view that ties the others together.
- [Step Waterfall](/docs/workflows/step-waterfall) — per-step timing as horizontal
  bars on a shared axis; see where a run spent its time.
- [API Call](/docs/workflows/api-call) — inspect a single HTTP exchange: method,
  URL and status, with request and response shown side by side.
- [Function](/docs/workflows/function) — inspect a single function execution: its
  input, output, console streams and the code that ran.
- [If / Else](/docs/workflows/conditional) — a breakdown table for a conditional
  routing step: every branch, each comparison, and which branch was taken.
