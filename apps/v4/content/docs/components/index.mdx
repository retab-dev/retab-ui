Retab UI components are headless and unstyled — install each as source with the
shadcn CLI and theme it to match your product.

## Primitives

- [Schema Builder](/docs/components/schema-builder) — author the JSON Schema that drives an extraction.
- [CSV Viewer](/docs/components/csv-viewer) — a virtualized CSV/TSV table built on TanStack Table and Virtual.
